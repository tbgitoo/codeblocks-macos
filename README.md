# Unofficial native Code::Blocks port for Apple Silicon macOS

This repository provides an unofficial native Apple Silicon macOS port of
Code::Blocks, based on Code::Blocks 25.03.

This project is independent of, and is not endorsed by, the official
Code::Blocks project.

## macOS users

Prebuilt versions are available as `.dmg` files from the **Releases** section
of this repository.

For download, installation, debugger and build information, see:

[README.macos.md](README.macos.md)

## Windows

For a general Windows install, use the official Code::Blocks distribution:

[Official Code::Blocks website](https://www.codeblocks.org)

From v4.0, this repository also publishes a Windows installer in the
**Releases** section. It may be useful when you want the debugger for a source
file that is not part of a Code::Blocks project, or the wizard updates in this
tree. Building the 64-bit IDE from source is described in
[README.windows.md](README.windows.md).

## Linux users

For Linux and the official Code::Blocks project, please visit:

[Official Code::Blocks website](https://www.codeblocks.org)

The upstream Code::Blocks source repository is:

```text
svn://svn.code.sf.net/p/codeblocks/code/trunk
```
