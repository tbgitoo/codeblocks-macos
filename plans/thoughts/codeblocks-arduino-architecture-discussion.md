The legacy Arduino wizard is architecturally obsolete and should not be repaired by updating its embedded Arduino build recipes. Arduino CLI provides a credible technical route for replacing it with a thin external-build integration, and Arduino CLI's debugging facilities may permit integration with the Code::Blocks debugger for supported hardware.

However, Arduino IDE 2 already provides build, upload and source-level debugging workflows. A replacement Code::Blocks integration should therefore be undertaken only if a demonstrable advantage emerges, most plausibly for development of larger conventional C/C++ source trees and libraries. Feasibility alone is not sufficient justification.
